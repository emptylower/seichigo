# 首页性能修复与验证（2026-09-22）

状态：本地修复、功能验证与 Lighthouse 三次中位数对照完成；**尚未部署**。

- 基线：`83dd7fda`。
- 修复分支：`codex/homepage-performance`。
- 对比对象：同机运行的 Next.js 生产构建。结果用于验证本次改动，不等同于线上 PageSpeed Insights 或真实用户 CrUX 指标。
- AdSense 加载及审核方式、Google Analytics 保持原样。

## 修复内容

1. 首屏插画预加载与 `<picture>` 使用相同断点，桌面选横版、手机选竖版；预加载仅声明 AVIF 并附带 MIME 类型，避免同时下载横竖版或两种格式。手机演示地图保留 `eager`、高优先级和单次预加载。
2. 第三屏行程缩略图全部改为 `lazy`，避免 React SSR 把前四项再次提升为预加载。
3. 热门作品与城市增加 128、160、240px 候选，修正两列、四列和桌面双栏的 `sizes`。生成 `srcSet` 时按候选宽度覆盖原有 `w`，保留原有 `q` 和其他参数；世界地图根据实际显示宽度及移动端裁切选择已有 1208px / 2416px 资源。
4. MapLibre CSS 从全局移至地图懒加载入口，首页不再加载地图样式。地图根容器使用明确的内联绝对定位，避免按需样式到达顺序改变布局。
5. 首屏输入框与打字机状态独立到小组件，缩小逐字更新范围；修复行程展示网格的隐式最小宽度，消除手机横向溢出。

本次地图验收覆盖显示与布局；本地服务日志另有 AniList 热榜刷新 400，因此不代表外部数据服务的完整集成验收。

构建 HTML 引用的首页 CSS 从 **3 个文件、gzip 34,153 字节**降至 **2 个文件、gzip 24,128 字节**，减少 10,025 字节，约 29.4%。口径为分别 gzip 压缩构建 CSS 文件后累加，不包含响应头；首页 CSS 不再包含 MapLibre，地图页面仍按需加载所需样式。

网络审计另记录样式传输量由 35,671 降至 25,250 字节，因包含传输开销，不与上述静态 gzip 数值混用。桌面基线同时请求竖版插画（48,142 字节）与横版（73,281 字节）；修复后只请求横版，消除约 48 KB 的重复背景传输。
