# plan 页多语言实施计划（2026-09-05）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/plan/start`、`/plan/[id]` 及其页头页脚按站点语言（路径前缀 > `NEXT_LOCALE` cookie > 浏览器语言）三语显示；助手回复由模型按用户提问语言自行跟随；服务端固定文案三语化。

**Architecture:** 一个纯函数统一解析请求语言，middleware 写进 `x-seichigo-locale` 头，服务端 `getLocale()` 读头，页面把 `locale` 逐层作为 prop 传给客户端组件，文案走现有 `t(key, locale)` 与 `lib/i18n/locales/*.json`。服务端固定文案（思维链短语、网络错误、接口错误、餐食标签）集中到 `lib/planAgent/serverText.ts` 三语字典。系统提示词正文不动，只删"中文回复"并追加"回复语言"段。

**Tech Stack:** Next.js 15 App Router、`lib/i18n`（`t()` + JSON）、vitest + testing-library、Prisma（只读关系查询，无迁移）。

设计稿：`docs/superpowers/specs/2026-09-05-plan-page-i18n-design.md`（所有取舍以它为准）。

## §0 契约

### 0.1 语言解析

```ts
// lib/i18n/resolveRequestLocale.ts
import type { SupportedLocale } from './types'
export function resolveRequestLocale(input: {
  pathname: string
  cookieHeader: string | null
  acceptLanguage: string | null
}): SupportedLocale
```

优先级：`/en`、`/ja` 路径前缀 → cookie `NEXT_LOCALE=(zh|en|ja)`（用正则 `(?:^|;\s*)NEXT_LOCALE=(zh|en|ja)(?:;|$)` 取，非法值忽略）→ `pickLocaleFromAcceptLanguage(acceptLanguage)` → `'zh'`。

- `middleware.ts`：`x-seichigo-locale` 改为 `resolveRequestLocale(...)` 的结果；重定向逻辑仍用路径前缀 `currentLocale`，行为不变。
- `lib/i18n/getLocale.ts`：先读 `x-seichigo-locale`（合法值直接返回），否则解析 `accept-language`，否则 `'zh'`。

### 0.2 服务端 locale 传递

- `app/(authed)/layout.tsx`：`const locale = await getLocale()`，`<SiteShellPublic locale={locale}>`。
- `app/(authed)/plan/[id]/page.tsx`：`<PlanPlanner locale={locale} ... />`。
- `app/(authed)/plan/start/locale.ts`：`parseStartLocale(raw): SiteLocale | null`（认不出返回 `null`）。
- `app/(authed)/plan/start/page.tsx`：`const fromQuery = parseStartLocale(searchParams?.locale)`；`locale={fromQuery ?? (await getLocale())}`，`syncLocaleCookie={fromQuery !== null}`。
- `PlanStartClient` 新增可选 prop `syncLocaleCookie?: boolean`：为 true 时挂载后写一次 cookie `NEXT_LOCALE=<locale>; path=/; max-age=31536000; SameSite=Lax`（与 `components/LanguageSwitcher.tsx` 的 `setLocaleCookie` 相同参数）。

### 0.3 客户端 prop

- `PlanPlanner` 新增 `locale?: SupportedLocale`（缺省 `'zh'`）；所有子组件同名可选 prop，缺省 `'zh'`，逐层显式传递，不用 context。
- 文案键 `pages.plan.<section>.<key>`，section：`sidebar`、`composer`、`chat`、`thinking`、`ask`、`day`、`transit`、`map`、`thumbnail`、`errors`、`common`。占位符沿用 `{name}` 风格（`t()` 不做替换，调用方 `.replace('{name}', value)`，与现有用法一致）。
- 日期时间：`Intl.DateTimeFormat` 语言标签映射 `zh→'zh-CN'`、`en→'en-US'`、`ja→'ja-JP'`，放 `lib/i18n/intlLocale.ts`：`export function toIntlLocale(locale: SupportedLocale): string`（A 建，B 用；B 若先跑到，在自己文件内先写同名局部函数，A 落地后 B 不必回改）。

### 0.6 服务端固定文案字典

```ts
// lib/planAgent/serverText.ts
import type { SupportedLocale } from '@/lib/i18n/types'
export type ServerTextDict = {
  status: {
    searchAnime: (query: string) => string          // 正在搜索作品「{q}」
    searchBangumi: (keyword: string) => string
    listPoints: string; clusterPoints: string; estimateTransit: string
    travelDriving: string; travelWalk: string; travelTransit: string
    resolvePlace: (query: string) => string
    readPlan: string; updateMeta: string; savePlan: string
    askDate: string; askWork: string; askOpinion: string; askGeneric: string
    processing: string
  }
  summary: { /* summarizeToolArgs 的所有分支 */ ... }
  result: { /* summarizeToolResult 的所有分支，含 failed:(msg)=>string, done */ ... }
  netError: string
  errors: {
    notSignedIn: string; planNotFound: string; forbidden: string; emptyMessage: string
    agentQuotaExhausted: string; planBusy: string; createQuotaExhausted: string
    invalidJson: string; emptyTitle: string; invalidStatus: string
  }
  meal: { breakfast: string; lunch: string; dinner: string }
  askUserNote: string   // loop.ts:557 那句
}
export function serverText(locale: SupportedLocale): ServerTextDict
```

- 三语键必须一致（用 `Object.keys` 递归比对的测试保证）。中文取现有原文，逐字不改。
- `statusPhrases.ts` 三个函数末尾加可选参数 `locale: SupportedLocale = 'zh'`，内部改用 `serverText(locale)`；现有中文断言不变。
- `netErrors.ts`：`agentErrorMessage(err, locale: SupportedLocale = 'zh')`；`AGENT_NETWORK_ERROR_MESSAGE` 保留为 zh 常量（现有测试用）。
- `PlanAgentDeps.locale?: SupportedLocale`（缺省 `'zh'`），loop 内所有 `toolStatusPhrase/summarizeToolArgs/summarizeToolResult/agentErrorMessage` 调用传入；`askUserNote` 取字典；`EnrichContext.locale?: SupportedLocale` 由 loop/tools 传入。
- `TripPlanHandlerDeps` 增加可选 `getLocale?: () => Promise<SupportedLocale>`（缺省 import `lib/i18n/getLocale`），handler 内错误响应改用 `serverText(await getLocale()).errors.*`；agent route 同理并把 `locale` 传给 `runPlanAgent`。
